# SlateMedia Premium Website
Open `index.html` directly or use VS Code Live Server.

Pages: index, services, about, pricing, work, contact, faq.
Shared assets: css/style.css and js/main.js.

The contact form validates input and prepares a mailto email to hello@slatemedia.in, so it works without a backend. Replace portfolio metrics, contact details and social links with verified business information before publishing. Images currently use remote Unsplash URLs; for production, download/host your final approved imagery.
